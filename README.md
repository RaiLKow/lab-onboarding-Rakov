# lab-onboarding-Rakov

Аудит клиентского компьютера

1. Базовый набор ПО и обоснование
Для нормальной офисной работы были выбраны 5 категорий:
* **Офисный пакет** (Office, LibreOffice, OpenOffice, МойОфис) — необходим для работы с документами и таблицами.
* **Браузер** (Chrome, Firefox, Edge, Яндекс) — доступ к корпоративным веб-ресурсам.
* **Программа для чтения PDF** (Acrobat, Foxit, SumatraPDF) — чтение регламентов и вложений из почты.
* **Архиватор** (7-Zip, WinRAR, WinZip) — работа с архивами.
* **Антивирус** (Defender, Kaspersky, ESET, Dr.Web) — базовая защита рабочего места.

*Примечание:* Браузер Edge встроен в Windows, поэтому его наличие не говорит о качественной настройке, но категория проверяется.

2. Признаки излишнего ПО
Для рекомендации к проверке используются 4 группы признаков:
1. **Игровое ПО:** Steam, Epic Games, GOG, Origin, Ubisoft Connect, Battle.net, Riot, game, gaming.
2. **Торренты:** torrent, uTorrent, BitTorrent, qBittorrent, Vuze.
3. **Мессенджеры:** Discord, Telegram, WhatsApp, Viber, Skype (формулировка рекомендации проверяющая, так как может быть рабочим инструментом).
4. **Развлечения:** Wallpaper Engine, OBS, Soundpad.

3. Проверка работоспособности логики

* **Проверка работы базового ПО:** 
  Скрипт успешно распознал установленные программы и подтвердил их наличие:
  - Офисный пакет: *Microsoft Office профессиональный плюс 2010*.
  - Браузер: *Microsoft Edge*.
  - Архиватор: *7-Zip 19.00 (x64)*.
  При этом скрипт корректно выявил отсутствие программ для чтения PDF и антивируса, выдав соответствующие рекомендации.

* **Проверка излишнего ПО:** 
  Логика анализа успешно обнаружила в системе программы из «серого» списка:
  - В категории «Игровое ПО» найдены: *Steam* и *GameGuard*.
  - В категориях «Торрент-клиенты», «Мессенджеры» и «Развлечения» ничего не найдено, о чем скрипт корректно сообщил (вывод «Не найдено — в порядке»).

4. Ограничения решения
* Анализ идет по подстроке в названии программы, что может давать редкие ложные срабатывания (например, программа *GameGuard* является античит-защитой от игр, но скрипт относит её к игровому ПО из-за слова "Game").
* Окончательное решение об удалении ПО всегда остается за человеком.
